# Anki Collaborative Add-on

*A little something I want you to know.*

## Overview

An LLM-powered Anki add-on that lets you send flashcards directly to other people's decks.

Anki is traditionally a tool for remembering things you choose to learn. But what about the things other people want to show you?

This add-on introduces a social dimension to spaced repetition. Instead of sending someone a text, you can send them a little flashcard — something interesting you learned, a fact you think they'd enjoy, an inside joke, or simply something you'd like them to know.

And unlike a text that gets buried in a messaging app, flashcards comes back!

## The Idea

Inspired by the concept of **epistemic trust**, this project explores what happens when we let other people participate in what we remember.

We use flashcards not just for studying, but also for learning things with and about each other.

**Try sending someone a flashcard instead of a text! Give them something to remember.**
